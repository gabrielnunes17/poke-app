# Poke App

Projeto React Native desenvolvido no curso de férias da Faculdade Senac Pernambuco, o app é uma Pokédex simplificada que permite salvar seus Pokemons favoritos.

## Requisitos

- Node.js
- Expo CLI
- Um emulador Android/iOS ou o app Expo Go no seu celular

## Clonar o repositório

```bash
git clone https://github.com/gabrielnunes17/poke-app.git
```

## Instalação

1. Entre na pasta do projeto:

   ```bash
   cd poke-app
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

## Tecnologias utilizadas

- React Native
- Expo
- React Navigation

## Executando a aplicação

Inicie o Metro Bundler com:

```bash
npx expo start
```

Após isso, o Expo abrirá um QR Code no terminal e exibirá opções de teclado, como:

- `a` para abrir no Android
- `i` para abrir no iOS
- `w` para abrir no navegador web
- `r` para recarregar a aplicação
- `m` para abrir o menu
- `?` para mostrar todos os comandos

Se estiver usando o celular, escaneie o QR Code com o app Expo Go.

Se estiver usando um emulador ou dispositivo conectado, você pode pressionar `a` para Android ou `i` para iOS.
